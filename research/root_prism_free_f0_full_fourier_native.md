prism-free and F-free split-shell case. It does not fix the second component
or its alignment. It does not realize the exterior edge graph.

passed. Their compressed specification hash is

## Exact preservation and preparation

The adapter first verifies the passed specification, preparation, cold
reports, and both owner records. It then checks every old local-table
projection against the actual parent protobuf table. The literal inverse
links are compared directly with all 480 denominator-12 Fourier inverse
certificates.

For each complete parent protobuf, the adapter replaces the 42 tables and
appends the suffix. It then deletes the new variables and rows and restores
the old table messages. The resulting raw protobuf hash must equal the
frozen whole-parent hash. Reapplying the changes must reproduce the same new
hash. This check covers the old variable messages, both joint tables, every
unchanged constraint, and their ordering.

Every coefficient, domain endpoint, product range, and absolute linear
box-activity bound is checked with Python integers before native use. The
mathematical Fourier specification has maximum coordinate magnitude 8,
maximum product magnitude 64, and maximum new Fourier-row activity 2,959.
The literal layer has its own exact activity checks.

Preparation uses pinned OR-Tools 9.15.6755 public constructors and requires
both an empty validator error and byte identity with the prepared initial
protobuf. It constructs no `CpSolver`. The full-target protobuf is released
before public reconstruction of the initial model to reduce simultaneous
copies. Stage records retain elapsed time and current/peak RSS.

One owner bounds preparation by 60 seconds. A separate 60-second owner
rebuilds the append from the certified inputs and compares the complete plan
and both saved protobufs. Cold replay does not repeat public native model
construction or the mathematical censuses. Failed, late, or partial outcomes
remain preserved.

## Future witness scope

A future native vector remains provisional until all full-target constraints,
the restored original parent, and the independent literal decoder pass exact
checks. The decoder must recover the selected literal masks and verify all
9,742 pair histograms, 172 original selector equations, motif and zero-pair
conditions, and all 4,416 literal inequalities.

The existing common core-group phase remains the only orientation
normalization. No independent sign or orientation is fixed for an orbit or
Fourier representation. Integer exterior-edge orbit counts are not an
exterior graph realization. A native infeasible status is not an exclusion
without a separately checkable proof.
