# Local matchings for the new direct incidence

The new sixty-signature incidence passes every one of the eighteen local
matching checks. Its shared exterior graph is nevertheless impossible.
The separate [complete exterior query and proof](root_prism_free_f0_fixed_selection_exterior_query_run01.md)
establish that contradiction with the second shell component unspecified.

This calculation concerns the conditional component-zero, split-shell case.
It does not establish a statement about every possible Conway graph.

## Input and local obligation

The [direct literal query](root_prism_free_f0_direct_literal_query_run01.md)
produces sixty distinct signature IDs. Their exact selection file has SHA-256
`6c1434b1dbb5a28f19707a3048cb43d64f14370856d03ef7496a3a58fabf4aaa`.
The saved vector satisfies every original equation and all 4,416 frozen cuts;
the direct check and its separate cold owner are bound in the intake record.

At each of eighteen fixed core vertices, exactly eight selected exterior
neighbors must pair into a perfect matching. The frozen
[candidate oracle](root_prism_free_f0_core_matching_candidate_oracle.md)
checks all 105 possible matchings on each eight-set. Its allowed edges use
the original eligibility conditions and the 162 already proved zero edge
orbits. A missing local matching would give an eight-selector exclusion.

For this incidence, all eighteen sets have a matching. The report retains
the actual witnesses. Exact replay reconstructs every set and checks each
witness against the frozen domain. This is eighteen separate existence
statements; compatibility of their shared edges is a further condition.
