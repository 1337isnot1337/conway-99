## Fixed model and scope

This package prepares a bounded query of the existing full Fourier count model after adding 6,854 core-matching blossom inequalities. It does not contain a production query result.

The new target has 32,296 variables and 65,811 constraints. Its initial model has 65,694 constraints. All variable IDs, 16,280 product constraints, 44 tables, and the 117-row external pool retain their previous meanings. Each added inequality comes from the complete, cold-checked three-vertex blossom family. The other 2,040 family rows are omitted only because their saved exact upper-box certificates imply them on the unchanged domains.

The full parent model is restored byte for byte when the appended rows are deleted. The separate native overlay package records that check, its failed missing-package attempt, the successful corrected-environment build, and the complete cold replay. This query package uses only the successful overlay02 archives.

A full-target integer vector would remain provisional until a separately approved restored-parent arithmetic checker and the independent Fourier-to-literal decoder accept it. Such acceptance would establish the specified count and selector-incidence obligations. It would not construct exterior adjacency or a 99-vertex graph.

## Frozen limits and acceptance

One production invocation is limited to a 300-second owned child and 180 cumulative native solve seconds. It uses one worker, seed zero, probing level zero, and linearization level zero. At most 12 native calls are permitted. After a returned integer vector, the driver may append the first at most 16 exactly violated external-pool rows in the frozen pool order. A later call requires a strictly larger certified prefix.

Every returned integer vector is saved before exact checks. Each call records the actual model hash and pool prefix. A native time overrun, killed child, incomplete result, or unproved numerical infeasibility cannot establish a count witness or an exclusion. No unchanged retry is authorized by this package.

The independent root gate is f0-core-matching-blossom-query-root-gate01.json, SHA-256 43d1235b238612965f5f763bfd1b4a81c22d0ec9b224a21a96f5c35238f53adb. At this package boundary, the count query is unrun.
