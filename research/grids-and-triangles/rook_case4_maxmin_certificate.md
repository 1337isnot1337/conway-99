## Model and exact upper bound

Let
`P={x in [0,1]^n : L <= A x <= U}`,
where all row endpoints are finite integers. Adjoin `t in [0,1]` and the rows `0 <= x_j-t <= 1`, then maximize `t`. Every original point lifts at `t=0`, so this extension preserves feasibility.

Write `z=(x,t)`, `C` for the extended matrix, and `e_t` for the last coordinate vector. For any integer row multipliers `lambda` and any integer `gamma>=0`, define

```text
u = sum_i max(lambda_i L_i, lambda_i U_i)
r = gamma e_t - C^T lambda
B = u + sum_j max(r_j,0).
```

Every feasible point satisfies `gamma t <= B`. This follows from the exact identity

```text
B - gamma t
 = sum_i [max(lambda_i L_i,lambda_i U_i)-lambda_i(Cz)_i]
   + sum_j [max(r_j,0)-r_j z_j].
```

Every summand is nonnegative. This directly accounts for both row endpoints and both variable bounds; it does not assume a solver's complementary-slackness report.

For `gamma=0`, an exact `B<0` is a finite-box Farkas contradiction. For `gamma>0`, an exact `B<0` also contradicts `t>=0`.

## Extracting forced selectors

Suppose `gamma>0` and `B=0`. Insert any original feasible point as `z=(x,0)`. Every nonnegative summand in the identity must vanish.

- A negative multiplier on `0<=x_j-t<=1` forces `x_j=0`.
- A positive multiplier on that row forces `x_j=1`.
- For an original selector coordinate, `r_j<0` forces `x_j=0`, and `r_j>0` forces `x_j=1`.
- A positive `r_t` contradicts existence of any original feasible point, since its variable-bound slack is then strictly positive at `t=0`.

If the original system is feasible, an exact zero objective bound necessarily exposes at least one selector zero. Indeed `r_t<=0`, and the original rows have no t coefficient. Consequently
`sum_j lambda_extension,j = r_t-gamma <0`.
At least one extension multiplier is negative.

An exactly checked rational feasible point with `t>0` instead proves that no remaining selector is identically zero on this relaxation. This does not construct a binary incidence design or a99-vertex graph.
