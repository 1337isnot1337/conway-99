# An exact grid-free witness for the existing order-nine relaxation

The existing order-nine count system and all 584 cached ordinary and
induced flag-moment blocks admit an exact integer count assignment with
zero rook grids. The assignment also gives zero copies of the forbidden
rook graph with one edge deleted. Every one of the 584 moment matrices
is positive definite, certified by integer congruences.

Consequently the minimum grid count in this specific finite relaxation is
exactly zero. Neither stronger grid-count upper bounds nor this collection
of count and moment constraints forces a rook grid to exist.

This is a count assignment, not a graph or an extension to higher orders.
It does not establish feasibility of every possible order-nine flag
inequality. The statement is limited to the count equations and the
explicit cached moment families checked below.

## The systems that were checked

The catalogue built by
[`subgraph_counts.py`](../../experiments/workspace/subgraph_counts.py)
contains all induced graph types through nine vertices satisfying

\[
|N_H(i)\cap N_H(j)|+(A_H)_{ij}\le2\qquad(i\ne j).
\]

This excludes every diamond and `K_(2,3)` as a subgraph, including diamonds
inside a `K_4`. Its level sizes are:

| 1 | 1 |

| 3 | 4 |

There are 6,535 types in total. The core reduction in
[`core_counts.py`](../../experiments/workspace/core_counts.py) expresses
their counts in 57 ordinary subgraph coordinates, corresponding to the
types with minimum degree at least three. All induced counts must be
nonnegative integers. The unreduced extension equations count outside
vertices, neighbors of marked vertices, and common neighbors of marked
pairs.

The exact verifier rebuilds the extension catalogue and checks all 23,189
original equations, all 6,535 induced counts, and divisibility of ordinary
embedding counts by the corresponding automorphism orders. It also checks
the total number of induced subsets at each order against `binomial(99,n)`.

The flag matrices are the existing caches generated by
[`flag_moments.py`](../../experiments/workspace/flag_moments.py). They use
the following root and extra-vertex parameters:

| --- | --- | ---: | ---: |

The largest matrix has order 242. Each matrix is an integer linear
combination of the embedding counts. Its positive semidefiniteness is
necessary because its entries sum products of rooted flag counts.

## The integer witness

In the existing 57-coordinate core order, the witness is:

```text
[326,367,735,163,326,10277,14097,1141,82,408,82,82,82,326,
 16005,82,16130,326,163,326,4076,163,1386,1631,652,82,408,
 489,82,82,82,163,7569,2243,23542,21800,489,489,18649,978,
 978,4837,82,1006,571,326,326,82,82,163,163,82,82,82,82,0,0]
```

The final two coordinates are the nine-vertex 17-edge broken rook and the
18-edge rook grid. Their ordinary and induced counts are both zero. The
verifier locates these types from their order and edge counts and checks
their vanishing; it does not merely assume the final entries have these
meanings.

This point was found by imposing both zero counts on the existing count
model, adding the 530 archived flag cuts, and separating against all 584
cached blocks. Three rounds added six exact integer cuts. The numerical
point had enough linear slack to round its 55 free coordinates to integers.
The final certificate verifies the integer point directly and does not
rely on the rounding argument or on the optimizer's status.

For context, the older archived `core9.log` witness already had zero grids
in the count equations alone. The new witness additionally satisfies all
of the cached ordinary and induced moment blocks exactly.

## Exact positive-definiteness certificates

For every integer moment matrix `M`, the saved certificate gives an
integer upper-triangular matrix `Q` with nonzero diagonal. The verifier
computes

\[
R=Q^T M Q
\]

using Python integer arithmetic and checks

\[
R_{ii}-\sum_{j\ne i}|R_{ij}|>0
\quad\text{for every row }i.
\]

These inequalities prove that `R` is positive definite. Explicitly,

\[
y^T R y=
\sum_i\left(R_{ii}-\sum_{j\ne i}|R_{ij}|\right)y_i^2
+\sum_{i<j}|R_{ij}|\left(y_i+\operatorname{sgn}(R_{ij})y_j\right)^2>0
\]

for every nonzero `y`. Since `Q` is invertible, `M` is positive definite
as well.

Floating-point Cholesky was used only to select candidate matrices `Q`
during certificate generation. Replay reads the saved integer matrices
and makes every sign decision by integer comparison. It also checks a
hash of each reconstructed integer moment matrix against the certificate.
There is no numerical eigenvalue threshold in the final proof.

An independent audit checked the normalization and all 429,428 saved
integer congruence entries. It also recomputed the sparse coefficient sums
with Python integers. Their maximum is 24; the largest resulting product
bound is 150,061,277,963,520, below `2^63`. The verifier now computes this
bound without fixed-width summation and explicitly rejects noninteger
congruence entries. The saved mathematical certificate is unchanged.

The compressed certificate is
`experiments/logs/moments-and-counts/grid-free-core9-certificate.json.gz`.
It contains the integer core vector and all 584 integer congruences. The
compressed size is approximately one megabyte.

```sh
.venv/bin/python experiments/workspace/grid_free_core9_certificate.py \
  --verify experiments/logs/moments-and-counts/grid-free-core9-certificate.json.gz
```

Generation is available separately with `--write`. The exploratory source
`grid_free_core9_probe.py` and its log retain the numerical search, but they
are not needed to replay the exact result. Existing caches, witnesses, and
cut files are read only.

## The global grid-free alternative remains open

The aggregate root/grid flag model has an even simpler exact zero-grid
point: all 99 root axis graphs are empty, every grid-type variable is zero,
and all 231 triangles have grid multiplicity zero. Its pair, cover,
crossing, and triangle-population constraints all hold.

The published closure result of Ibrahim, LaFayette, and McCall,
[Theorem 4.19, page 84](https://ajc.maths.uq.edu.au/pdf/93/ajc_v93_p060.pdf),
states that a hypothetical `(99,14,1,2)` graph has no rook grids exactly
when every nonadjacent pair percolates to the whole graph. It does not
assert a positive lower bound on the grid count. In the grid-free case all
4,158 nonadjacent pairs would have that property.

The exact witness above prevents a positive grid lower bound from being
deduced from this particular finite count/PSD system. A contradiction for
the actual graph would need an additional condition that this witness
fails; its existence does not settle whether the witness can arise from
any graph.
